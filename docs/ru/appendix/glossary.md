# Приложение A — Glossary

| Термин | Определение |
|--------|-------------|
| **AS (Autonomous System)** | Набор IP-сетей под единым административным контролем, идентифицируемый ASN |
| **ASN** | Autonomous System Number — уникальный идентификатор для BGP routing |
| **BGP** | Border Gateway Protocol — междоменный протокол маршрутизации для выбора пути в интернет |
| **check-gateway** | Параметр маршрута MikroTik, мониторящий доступность шлюза через ping или ARP |
| **Connection Mark** | Постоянная метка, назначаемая соединению в таблице conntrack |
| **Connection Tracking** | Stateful inspection engine, отслеживающий активные сетевые сессии |
| **Conntrack** | Сокращение от Connection Tracking |
| **ECMP** | Equal-Cost Multi-Path — маршрутизация по нескольким путям с равной метрикой |
| **Failover** | Автоматическое переключение на резервный путь при отказе основного |
| **FIB** | Forwarding Information Base — фактическая таблица маршрутизации для пересылки пакетов |
| **Hairpin NAT** | NAT loopback, позволяющий LAN-клиентам обращаться к публичному IP изнутри сети |
| **ISP** | Internet Service Provider |
| **LB** | Load Balancing |
| **Mangle** | Цепочка firewall MikroTik для модификации пакетов/соединений и marking |
| **Masquerade** | Dynamic source NAT с использованием IP исходящего интерфейса |
| **MSS** | Maximum Segment Size — максимальный TCP payload на пакет |
| **MTU** | Maximum Transmission Unit — максимальный размер frame на интерфейсе |
| **Multi-WAN** | Сетевая архитектура с несколькими internet uplinks |
| **NAT** | Network Address Translation |
| **Netwatch** | Инструмент MikroTik для мониторинга доступности хостов со скриптами |
| **NPT** | IPv6 Network Prefix Translation |
| **PCC** | Per Connection Classifier — hash-based per-session WAN assignment |
| **PCQ** | Per Connection Queue — справедливое распределение bandwidth per connection/IP |
| **PI Space** | Provider-Independent IP address block |
| **PMTUD** | Path MTU Discovery |
| **PPPoE** | Point-to-Point Protocol over Ethernet |
| **Recursive Routing** | Разрешение доступности шлюза через промежуточные маршруты |
| **Routing Mark** | Метка пакета, определяющая, какую таблицу маршрутизации использовать |
| **Routing Table** | Набор маршрутов для принятия forwarding decisions |
| **Scope** | Атрибут маршрута MikroTik, управляющий recursive resolution |
| **SLA** | Service Level Agreement |
| **Src-NAT** | Source NAT с фиксированным адресом трансляции |
| **VRF** | Virtual Routing and Forwarding — изолированный экземпляр маршрутизации |
| **WAN** | Wide Area Network — internet-facing interface |
| **WISP** | Wireless Internet Service Provider |
