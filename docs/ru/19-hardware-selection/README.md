## 19.3 CPU и производительность PCC

Правила PCC mangle потребляют CPU на каждое **новое соединение**. При выборе оборудования учитывайте скорость создания соединений, а не только пропускную способность.

| Метрика | hEX | RB4011 | CCR2004 | CCR2116 |
|--------|-----|--------|---------|---------|
| Новых conn/sec | ~500 | ~5,000 | ~20,000 | ~80,000 |
| Активных соединений | 50K | 200K | 500K | 2M+ |
| PCC 3-WAN CPU @ 1Gbps | 60–80% | 15–25% | 5–10% | < 5% |
| Рекомендуемое число WAN для PCC | 2 | 3 | 3–4 | 4+ |

**Правило:** если устойчивая скорость новых соединений превышает 2000/sec — используйте серию CCR.

## 19.4 Требования к RAM

| Компонент | Использование RAM |
|-----------|-----------|
| Базовый RouterOS | ~50MB |
| Connection tracking (100K записей) | ~200MB |
| BGP full table | ~2–4GB |
| Только BGP default | ~50MB |
| PCC mangle (без доп. RAM) | Только CPU |
| User Manager (500 пользователей) | ~100MB |

| Развёртывание | Минимум RAM |
|------------|-------------|
| Базовый Multi-WAN | 256MB |
| Enterprise PCC | 1GB |
| ISP с 500K соединений | 4GB |
| BGP full table | 8–16GB |

## 19.5 Хранилище и логирование

| Модель | Хранилище | Ёмкость логирования |
|-------|---------|-----------------|
| hEX S | 16MB NAND | Минимальная — используйте remote syslog |
| RB4011 | 512MB NAND | Умеренная |
| CCR2004 | 128MB NAND + USB | Хорошая с USB-диском |
| CCR2116 | 128MB NAND + NVMe slot | Отличная |

Для production Multi-WAN всегда используйте **remote Syslog** независимо от модели.

---

## 19.6 Планирование количества интерфейсов

| Тип WAN | Необходимые интерфейсы |
|----------|------------------|
| 2 ISP static fiber | 2 WAN + 1 LAN = 3 |
| 3 ISP mixed | 3 WAN + 1 LAN + 1 mgmt = 5 |
| ISP с VLAN handoff | 1 физический + VLANs |
| PPPoE × 3 | 3 физических WAN-порта |
| Dual router VRRP | 2× всё |

**Минимум:** 1 LAN + N WAN + 1 management port

## 19.7 Резервное питание и условия эксплуатации

| Требование | Enterprise | ISP |
|-------------|-----------|-----|
| Dual PSU | Рекомендуется | Обязательно |
| Rack mount | RB4011 1U или CCR | CCR 1U |
| Температура | < 40°C ambient | < 35°C с обдувом |
| UPS | Обязательно | Обязательно с генератором |
| Out-of-band mgmt | Выделенный mgmt port | Serial + выделенный mgmt |
