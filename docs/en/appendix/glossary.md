# Appendix A — Glossary

| Term | Definition |
|------|-----------|
| **AS (Autonomous System)** | Collection of IP networks under single administrative control, identified by ASN |
| **ASN** | Autonomous System Number — unique identifier for BGP routing |
| **BGP** | Border Gateway Protocol — inter-domain routing protocol for internet path selection |
| **check-gateway** | MikroTik route parameter that monitors gateway reachability via ping or ARP |
| **Connection Mark** | Persistent label assigned to a connection in the conntrack table |
| **Connection Tracking** | Stateful inspection engine tracking active network sessions |
| **Conntrack** | Short for Connection Tracking |
| **ECMP** | Equal-Cost Multi-Path — routing across multiple equal-metric paths |
| **Failover** | Automatic switch to backup path when primary fails |
| **FIB** | Forwarding Information Base — actual routing table used for packet forwarding |
| **Hairpin NAT** | NAT loopback allowing LAN clients to reach public IP from inside |
| **ISP** | Internet Service Provider |
| **LB** | Load Balancing |
| **Mangle** | MikroTik firewall chain for packet/connection modification and marking |
| **Masquerade** | Dynamic source NAT using the outbound interface IP |
| **MSS** | Maximum Segment Size — largest TCP payload per packet |
| **MTU** | Maximum Transmission Unit — largest frame size on an interface |
| **Multi-WAN** | Network design with multiple internet uplinks |
| **NAT** | Network Address Translation |
| **Netwatch** | MikroTik tool for monitoring host reachability with scripts |
| **NPT** | IPv6 Network Prefix Translation |
| **PCC** | Per Connection Classifier — hash-based per-session WAN assignment |
| **PCQ** | Per Connection Queue — fair bandwidth sharing per connection/IP |
| **PI Space** | Provider-Independent IP address block |
| **PMTUD** | Path MTU Discovery |
| **PPPoE** | Point-to-Point Protocol over Ethernet |
| **Recursive Routing** | Resolving gateway reachability through intermediate routes |
| **Routing Mark** | Packet label directing which routing table to consult |
| **Routing Table** | Collection of routes used for forwarding decisions |
| **Scope** | MikroTik route attribute controlling recursive resolution |
| **SLA** | Service Level Agreement |
| **Src-NAT** | Source NAT with fixed translation address |
| **VRF** | Virtual Routing and Forwarding — isolated routing instance |
| **WAN** | Wide Area Network — internet-facing interface |
| **WISP** | Wireless Internet Service Provider |
