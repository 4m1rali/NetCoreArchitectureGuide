# پیوست الف — واژه‌نامه

| اصطلاح | تعریف |
|--------|-------|
| **AS (Autonomous System)** | مجموعه شبکه‌های IP تحت کنترل اداری واحد، شناسایی‌شده با ASN |
| **ASN** | Autonomous System Number — شناسه یکتا برای مسیریابی BGP |
| **BGP** | Border Gateway Protocol — پروتکل مسیریابی بین‌دامنه برای انتخاب مسیر اینترنت |
| **check-gateway** | پارامتر Route میکروتیک که دسترسی Gateway را از طریق ping یا ARP مانیتور می‌کند |
| **Connection Mark** | برچسب پایدار اختصاص‌یافته به Connection در جدول conntrack |
| **Connection Tracking** | موتور بازرسی Stateful که Sessionهای شبکه فعال را ردیابی می‌کند |
| **Conntrack** | مخفف Connection Tracking |
| **ECMP** | Equal-Cost Multi-Path — مسیریابی در چند مسیر با Metric برابر |
| **Failover** | سوئیچ خودکار به مسیر پشتیبان هنگام قطع مسیر اصلی |
| **FIB** | Forwarding Information Base — جدول مسیریابی واقعی برای Forward بسته |
| **Hairpin NAT** | NAT loopback که به کلاینت‌های LAN اجازه می‌دهد IP عمومی را از داخل برسند |
| **ISP** | Internet Service Provider |
| **LB** | Load Balancing |
| **Mangle** | زنجیره Firewall میکروتیک برای تغییر بسته/Connection و Marking |
| **Masquerade** | Src-NAT پویا با استفاده از IP اینترفیس خروجی |
| **MSS** | Maximum Segment Size — بزرگ‌ترین Payload TCP در هر بسته |
| **MTU** | Maximum Transmission Unit — بزرگ‌ترین اندازه Frame روی Interface |
| **Multi-WAN** | طراحی شبکه با چند Uplink اینترنت |
| **NAT** | Network Address Translation |
| **Netwatch** | ابزار میکروتیک برای مانیتور دسترسی Host با اسکریپت |
| **NPT** | IPv6 Network Prefix Translation |
| **PCC** | Per Connection Classifier — تخصیص WAN به‌ازای هر Session با Hash |
| **PCQ** | Per Connection Queue — اشتراک عادلانه پهنای باند به‌ازای هر Connection/IP |
| **PI Space** | بلوک IP مستقل از Provider |
| **PMTUD** | Path MTU Discovery |
| **PPPoE** | Point-to-Point Protocol over Ethernet |
| **Recursive Routing** | حل دسترسی Gateway از طریق Routeهای میانی |
| **Routing Mark** | برچسب بسته که مشخص می‌کند کدام جدول مسیریابی بررسی شود |
| **Routing Table** | مجموعه Routeها برای تصمیم Forwarding |
| **Scope** | ویژگی Route میکروتیک که حل Recursive را کنترل می‌کند |
| **SLA** | Service Level Agreement |
| **Src-NAT** | Source NAT با آدرس ترجمه ثابت |
| **VRF** | Virtual Routing and Forwarding — نمونه مسیریابی ایزوله |
| **WAN** | Wide Area Network — Interface رو به اینترنت |
| **WISP** | Wireless Internet Service Provider |
