# فصل ۱۷ — مطالعات موردی واقعی

> سناریوهای استقرار Production با تصمیمات معماری و درس‌های آموخته‌شده.

## مطالعه موردی ۱ — ISP WISP (۳۰۰ مشترک)

### محیط

| مورد | جزئیات |
|------|--------|
| روتر | MikroTik CCR2116-12G-4S+ |
| WAN-1 | Fiber 1Gbps (Upstream اصلی) |
| WAN-2 | Wireless backhaul 500Mbps (ثانویه) |
| WAN-3 | LTE 50Mbps (پشتیبان اضطراری) |
| مشترکین | ۳۰۰ مشتری PPPoE |
| چالش | توزیع یکنواخت ترافیک بدون قطع Session |

### راه‌حل

- PCC 2-way (WAN1 + WAN2) — LTE از PCC مستثنی
- Masquerade به‌ازای هر WAN برای NAT PPPoE
- PCQ rate limiting به‌ازای هر مشترک
- Netwatch روی هر دو Gateway اصلی
- Failover LTE فقط distance=3

### نتایج

| معیار | قبل | بعد |
|-------|-----|-----|
| Uptime | 97.2% | 99.7% |
| میانگین Latency | 45ms | 28ms |
| شکایت/ماه | 40 | 5 |
| تعادل استفاده WAN | 90/10 | 52/48 |

### درس آموخته‌شده

> LTE هرگز نباید در Classifier PCC باشد — یک استریم Netflix کل سهمیه ماهانه LTE را در ۴ ساعت مصرف کرد.

## مطالعه موردی ۲ — دفتر مرکزی Enterprise (۲۰۰ کارمند)

### محیط

| مورد | جزئیات |
|------|--------|
| روتر | MikroTik RB4011iGS+RM |
| WAN-1 | MPLS 200Mbps (سازمانی) |
| WAN-2 | Broadband 1Gbps (اینترنت) |
| WAN-3 | 4G LTE 100Mbps (پشتیبان) |
| سرویس‌ها | VoIP، ERP، Microsoft 365، WiFi مهمان |
| چالش | کیفیت VoIP + جداسازی مهمان |

### راه‌حل

- Policy routing: زیرشبکه VoIP → WAN1 (MPLS)
- Policy routing: ERP → WAN1
- PCC 2-way برای ترافیک عمومی (WAN2 + WAN3)
- VLAN جداگانه برای WiFi مهمان با PCC فقط روی WAN2
- صف اولویت QoS برای VoIP روی WAN1

### نتایج

| معیار | مقدار |
|-------|-------|
| امتیاز MOS VoIP | 4.2 (عالی) |
| Latency ERP | 12ms (MPLS) |
| پهنای باند مهمان | محدود 200Mbps |
| زمان Failover | 8 ثانیه (LTE) |

### درس آموخته‌شده

> قوانین Policy routing باید **بالای** قوانین PCC قرار گیرند. در استقرار اولیه VoIP از PCC عبور می‌کرد — تماس‌ها هر ۳۰ ثانیه قطع می‌شد.

## مطالعه موردی ۳ — لبه Datacenter (BGP)

### محیط

| مورد | جزئیات |
|------|--------|
| روتر | MikroTik CCR2216-1G-12XS-2XQ |
| ASN | 65050 (خصوصی) با PI space 203.0.113.0/24 |
| WAN-1 | BGP peer ISP-A (10G) |
| WAN-2 | BGP peer ISP-B (10G) |
| چالش | کنترل مسیر ورودی + خروجی |

### راه‌حل

- BGP به هر دو ISP با Advertise 203.0.113.0/24
- AS-PATH prepend روی ISP-B (ترجیح پشتیبان)
- ECMP برای خروجی (بدون NAT — IP عمومی)
- فیلتر Route BGP — فقط Accept default
- PCC لازم نیست

### نتایج

| معیار | مقدار |
|-------|-------|
| کنترل ورودی | کامل (انتخاب مسیر BGP) |
| ECMP خروجی | 50/50 در لینک‌های 10G |
| Failover | < 30 ثانیه (BGP hold timer) |
| حداکثر یک Stream | 10Gbps (یک مسیر) |

## مطالعه موردی ۴ — شعبه (۲۵ کاربر)

### محیط

| مورد | جزئیات |
|------|--------|
| روتر | MikroTik hEX S (RB760iGS) |
| WAN-1 | Cable 200Mbps |
| WAN-2 | DSL 50Mbps |
| چالش | CPU محدود روتر برای mangle |

### راه‌حل

- فقط Failover ساده (بدون PCC) — Cable اصلی، DSL پشتیبان
- Weighted: Cable تا زمان قطع 100٪ را حمل می‌کند
- Masquerade پایه روی WAN فعال
- check-gateway=ping روی هر دو Route

### نتایج

| معیار | مقدار |
|-------|-------|
| استفاده CPU | 15٪ (بدون سربار mangle) |
| زمان Failover | 12 ثانیه |
| صرفه‌جویی هزینه ماهانه | $0 (DSL از قبل قرارداد داشت) |

### درس آموخته‌شده

> هر استقرار به PCC نیاز ندارد. برای < 50 کاربر با سرعت WAN نامتقارن، فقط Failover ساده‌تر و پایدارتر روی سخت‌افزار پایین‌رده است.

## مطالعه موردی ۵ — هتل (۱۵۰ اتاق + WiFi مهمان)

### محیط

| مورد | جزئیات |
|------|--------|
| روتر | MikroTik CCR2004-16G-2S+ |
| WAN-1 | Fiber 500Mbps |
| WAN-2 | Fiber 500Mbps (ISP متفاوت) |
| WAN-3 | LTE 100Mbps پشتیبان |
| چالش | ۱۵۰ Session استریم همزمان |

### راه‌حل

- PCC 3-way توزیع مساوی
- PCQ rate limit به‌ازای هر اتاق (20Mbps down / 5Mbps up)
- DNS اجباری از طریق Cache روتر
- Hairpin NAT برای سیستم رزرو داخلی
- Hotspot روی VLAN مهمان با PCC

### نتایج

| معیار | مقدار |
|-------|-------|
| استریم همزمان پشتیبانی‌شده | 120+ |
| تعادل PCC | 34/33/33 |
| شکایت مهمان | تقریباً صفر |
| Failover در تعمیر ISP | شفاف (8s) |

## چارچوب تصمیم‌گیری از مطالعات موردی

| کاربران | انواع WAN | پیشنهاد |
|---------|-----------|---------|
| < 50 | هر نوع | فقط Failover |
| 50–200 | ۲–۳ با سرعت مشابه | PCC + Failover |
| 200–1000 | ۲–۳ + LTE پشتیبان | PCC + Policy + Failover |
| 1000+ | قابلیت BGP | BGP یا PCC روی CCR |
| ISP/WISP | چند Upstream | PCC + PCQ + Netwatch |
